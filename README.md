# Spring Boot Onboarding

A hands-on Java and Spring Boot learning project
## Tech Stack

- **Language:** Java 21
- **Framework:** Spring Boot
- **Build Tool:** Maven
- **Database:** PostgreSQL
- **ORM:** Spring Data JPA / Hibernate
- **Testing:** JUnit 5
- **Containerization:** Docker
- **Version Control:** Git and GitHub
