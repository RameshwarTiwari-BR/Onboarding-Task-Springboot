# Day 1 – Java Fundamentals

## Topics Covered

1. JDK vs JVM vs JRE
2. Java compilation and execution
3. Java main method
4. Packages and imports
5. Primitive data types
6. String and String immutability
7. Compile-time vs runtime errors

## Practical Exercises

### 1. HelloJava
Created a basic Java program to understand class declaration, the main method, and console output.

### 2. Celsius Converter
Created a Celsius to Fahrenheit converter

Formula:  F = (C × 9/5) + 32

### 3. Error Handling Concepts

Explored:
- Compile time errors: Type mismatch and syntax errors.
- Runtime errors: ArithmeticException caused by division by zero.



## Key Learnings

- Understood Java development and execution architecture.
- Learned how Java source code is compiled into bytecode.
- Understood Java static type system.
- Practiced variables, primitive types, Strings and Scanner.
- Understood the difference between compile-time and runtime errors.
